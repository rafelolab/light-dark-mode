## 📌 About the Project | Sobre o Projeto

**EN**

This project is a simple web interface that allows users to switch between light and dark themes using an interactive toggle switch.

It was developed as a learning project to practice JavaScript fundamentals, DOM manipulation, and CSS styling.

**PT-BR**

Este projeto é uma interface web simples que permite alternar entre os temas claro e escuro por meio de um botão interativo.

Foi desenvolvido como um projeto de aprendizado para praticar fundamentos de JavaScript, manipulação do DOM e estilização com CSS.



## ✨ Features | Funcionalidades

- 🌞 **Light mode** – Switches to a light theme.
  - **Tema claro** – Alterna a interface para o tema claro.

- 🌙 **Dark mode** – Switches to a dark theme.
  - **Tema escuro** – Alterna a interface para o tema escuro.

- 🎨 **Smooth transitions** – Provides smooth color transitions.
  - **Transições suaves** – Apresenta transições suaves entre as cores.

- 📝 **Dynamic text updates** – Updates the displayed text according to the selected theme.
  - **Atualização dinâmica de texto** – Atualiza o texto exibido de acordo com o tema selecionado.

- 🎛️ **Interactive toggle switch** – Allows users to switch between themes.
  - **Botão interativo** – Permite alternar entre os temas.



## 🛠️ Technologies | Tecnologias

- **HTML5** – Page structure.
  - **HTML5** – Estrutura da página.

- **CSS3** – Styling, layout, colors, and transitions.
  - **CSS3** – Estilização, layout, cores e transições.

- **JavaScript** – Theme switching, event handling, and DOM manipulation.
  - **JavaScript** – Alternância de temas, tratamento de eventos e manipulação do DOM.
